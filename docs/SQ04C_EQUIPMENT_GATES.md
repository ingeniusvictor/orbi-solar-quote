# SQ-04C — Base de validación de equipos

Se incorpora un registro tipado de equipos con cinco controles independientes: fuente, SEC, AFCI, precio fechado e ingeniería eléctrica. Una ficha de fabricante no equivale a autorización SEC ni a precio real.

La referencia GoodWe GW5000-DNS-30 se mantiene exclusivamente informativa. No se ha comprobado variante chilena, AFCI ni inscripción vigente SEC. La batería se representa como un marcador sin marca/modelo confirmado; no se publica capacidad ficticia.

Regla de seguridad: la función de cribado nunca devuelve «aprobado para instalar». La revisión eléctrica se mantiene pendiente aunque los campos de evidencia fueran completados, hasta contar con un proceso de ingeniería separado y verificable.

Esta etapa es fundacional, sin cambios de UI ni selección comercial automática. Próximos pasos: obtención y verificación manual de fichas regionales, modelos SEC exactos y proveedores con fecha de precios.
